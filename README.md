# c0m.me Account Center

Central account, identity, and application hub for the c0m.me ecosystem.

## Stack

- PHP 8.2+
- MariaDB / MySQL
- PDO
- HTML, CSS, vanilla JavaScript

## Status

Phase 1 is under active development. This repository is not production-ready yet.

## Installation

1. Upload the project files to your cPanel account.
2. Point the domain document root to `public/`.
3. Ensure PHP 8.2+ and PDO MySQL are enabled.
4. Open `/installer/` and follow the setup wizard.
5. Delete or deny web access to the installer after installation.

See `docs/INSTALLATION.md` for details.
